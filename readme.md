# Instagram Login Clone

A responsive Instagram-style login page clone built with HTML and CSS.

## About the Project

This project is a visual clone of an Instagram-style login page.  
It was created as a front-end practice project focused on layout, spacing, forms and responsive design.

## Features

- Instagram-style login layout
- Phone preview section
- Login form
- Signup box
- App download buttons
- Responsive design
- Mobile-friendly layout

## Technologies Used

- HTML
- CSS
- Git
- GitHub Pages

## What I Learned

While building this project, I practiced:

- HTML structure
- Semantic layout
- CSS Flexbox
- Form styling
- Responsive breakpoints
- Mobile-first thinking
- Git and GitHub workflow
- Deploying a static website with GitHub Pages

## Project Status

Finished as a front-end clone practice project.
