# Instagram Login Clone

A responsive Instagram-style login page clone built with HTML and CSS.

## Live Demo

[View Live Website](https://sonkata.github.io/instagram-login-clone/)

## About the Project

Instagram Login Clone is a front-end practice project focused on recreating a familiar login page layout using HTML and CSS.

The goal of this project was to practice layout structure, spacing, form styling, responsive behavior and visual accuracy.

This project helped me improve my understanding of HTML structure, CSS positioning, responsive design and clean UI recreation.

## Features

- Instagram-style login page layout
- Phone preview section
- Login form
- Sign up section
- App download section
- Responsive design
- Clean spacing and alignment
- Mobile-friendly layout
- GitHub Pages deployment
